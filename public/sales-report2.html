本期 7 列 销售额(C) ← 接口 销售金额；毛利额(D) ← 含税毛利；毛利率(E) = D÷C；来客数(F) ← 交易笔数；客单价(G) = C÷F
同比 5 列（H~L） 同比销售额(H) ← 同比调用的 对期销售金额；同比毛利额(I) ← 对期含税毛利；同比毛利率(J) = I÷H；同比来客数(K) ← 对期交易笔数；同比客单价(L) = H÷K
环比 5 列（M~Q） 环比销售额(M) ← 环比调用的 对期销售金额；环比毛利额(N) ← 对期含税毛利；环比毛利率(O) = N÷M；环比来客数(P) ← 对期交易笔数；环比客单价(Q) = M÷P
增长率 8 列（R~Y） 同比销售额增长率(R) = (C−H)÷H；环比销售额增长率(S) = (C−M)÷M；同比毛利额增长率(T) = (D−I)÷I；环比毛利额增长率(U) = (D−N)÷N；同比来客数增长率(V) = (F−K)÷K；环比来客数增长率(W) = (F−P)÷P；同比客单价增长率(X) = (G−L)÷L；环比客单价增长率(Y) = (G−Q)÷Q
→ 以上全部由前端公式计算（接口只提供原始值 + 对期值）

五、与 Excel 示例缓存值的核对结论（重要）

1. 增长率显示格式：Excel 单元格格式为百分比，缓存值存小数（如 0.1123 = 11.23%）；页面显示 11.23% —— 数值一致。
2. 销售额/毛利额/同比环比/增长率：接口 8/10 数据与 Excel 缓存一致（如 巨野中心店 销售额 490,232.55 两边完全相同）。
3. 「来客数 / 客单价」口径不同：Excel 示例的来客数（如 巨野中心店 6,504）不等于 接口「交易笔数」（21,691），接口也没有独立的「来客数」字段。Excel 客单价 = 销售额÷Excel来客数（75.37 = 490,232.55÷6,504），而页面按指定映射「来客数→交易笔数」展示。
若要完全对齐 Excel 的来客数/客单价，需提供该「来客数」的数据来源，再调整映射。
4. 机构清单差异：不同日期门店营业状态不同，机构清单会随日期变化 —— 属正常。
